🔀 Lesson 4: If-Else

If-Else is used to make decisions in Python.

💡 How does If-Else work?

If a condition is true, Python runs one block of code. Otherwise, it runs the else block.

💻 Example

age = 18

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote yet")
